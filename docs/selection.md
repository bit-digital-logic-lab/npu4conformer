# 文件价值筛选

| 级别 | 入库原则 | 例子 |
|---|---|---|
| A | 可复用、可修改、支撑构建或真实结论 | HLS/RTL、通信、仿真、黄金比较器、成功与失败报告、必要的第三方依赖 |
| B | 帮助理解或追溯 | 协议、固定版本、源文件哈希、模型配置、LayerNorm 聚合摘要 |
| C | 作为复现资产或历史记录保留在本地 | 权重、含参数的二进制输入、黄金张量、位流、旧版重复快照 |
| D | 可重新生成的环境和缓存 | `.venv`、`__pycache__`、Vivado/HLS 构建目录、临时日志 |

## 主要筛选决策

- 以 `src_hls/` 为单头项目的权威 HLS 源码。另一个 `hls/` 目录有旧版固定点类型转换，构建脚本实际引用 `src_hls/`，因此旧目录不入库。
- 保留 `rtl/generated/` 的 Verilog、ROM `.dat` 和 `sources.txt`，因为 Vivado 直接构建需要它们；不保留整个 HLS solution。
- `fixtures/input.bin` 包含五组投影参数和偏置，不能当作不含模型参数的普通输入样例。它和 `.pth`、`.pt`、`.npz` 使用外部资产方式准备。
- V5 首例与第二例的报告均入库。第二例失败摘要、独立比较器和检查点诊断是优先保留项。
- 恢复原导出缺失的 `golden_validation/scripts/golden_common.py`，其来源是首例运行归档副本；第二例使用独立的 `golden_case0001.py`，不混用两者。
- V5 依赖 V2 的主机执行器、数值 RTL 和黄金读取器。保留冻结源码及原清单；原清单列举的位流/张量等需在本地复现时另外恢复，不能称精简目录是完整冻结包。
- verilog-ethernet 只保留当前 Tcl 明确引用的模块、约束助手和原许可证，排除其他板卡示例。
- LayerNorm 摘要明确标记为 GPU 软件实验。原包未包含其完整实验驱动源码，保留结果和来源哈希，不包装成可重新运行的软件项目。
- 排除系统事件快照、DLL 调查记录、组会提纲等与源码复用关系较弱的材料。
