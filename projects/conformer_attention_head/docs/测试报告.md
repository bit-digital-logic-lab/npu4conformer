# 全 FPGA 单头最终测试报告

## 结论

最终位流已经通过 HLS C 仿真、C/RTL 联合仿真、Vivado 实现和实物 FPGA 验证。最终实物三组共 14,225 个 FP32 输出值，整个结果字节流与独立整数参考完全一致。各测试使用同一个最终位流。

指定 head 的全部推理运算均由 FPGA 执行。实物主机端仅有文件/串口字节传输、CRC 和 IEEE754 解包；无主机量化、矩阵乘、相对位置计算、Softmax、偏置相加或反量化。PyTorch 和整数参考在收到完整 FPGA 输出后作为独立测试运行。

## 3. mask 与通信覆盖

| 测试 | 覆盖内容 | 最终结果 |
|---|---|---|
| T=1 | 单个可见 token，最小长度 | PASS |
| T=4 | 最后一个 key 为 padding | PASS |
| T=8 | 最大长度，最后一个 key 屏蔽，query 索引 2 全屏蔽 | PASS |
| CRC 破坏 | T=1 输入包 tag=2 的 CRC 故意翻转一位 | FPGA 返回 status=1，重传后 PASS |
| 重复包 | T=1 输入包 tag=7 额外发送一次 | 只确认一次额外 ACK，完整输出仍逐位一致 |

T=8 的 query 索引 2：概率、context、contribution 均为 0；加 bias 的输出保留共享偏置。单元测试还验证修改被屏蔽 token 的数值，不会改变其他有效 query 的结果。

最终串口记录：

- T=1：323 个正常分包，1 次故意 CRC 错误的重试，再加 1 个额外重复诊断包，共 325 次输入包发送。
- T=4：326 个分包，无重试。
- T=8：330 个分包，实际遇到 3 次 status=2（framing error 或收包超时），自动重试后共 333 次发送，最终结果 CRC 及全部数值均通过。
- 统计文件中的 wire_attempts 不含专门重复诊断包；汇总文件另存 uart_transactions_including_duplicate。

通信链路存在可恢复的偶发收包错误，因此工程保留包序号、CRC、超时、有限重试和重复包抑制。最终结果 CRC 错误时会停止本次运行，不静默接受输出。

证据：artifacts/verified_t1、verified_t4、verified_t8 中的 transport.json、fpga_output.bin、verification.json 及对应日志。

C/RTL 联合仿真记录 3,905,841 个时钟周期；在 50 MHz 下约 78.117 ms。该值由测试台直接向 FIFO 提供数据得到，不包括 UART；不能用它代替约 60 秒的实物端到端耗时。

指数插值单测最初仅按查表插值估计上界，遗漏了 Q20 输入舍入。最终测试使用推导出的上界 h²/8 + 0.5/2²⁰ + 2/2³⁰，约 2.386×10⁻⁶；实际扫描最大误差约 2.318×10⁻⁶，通过。没有为此修改算法或浮点输出误差阈值。

| 最差保持时间裕量 WHS | +0.020 ns |

Vivado 报告 All user specified timing constraints are met。完整报告为 utilization.rpt 和 timing_summary.rpt。

最后保留 15 条 DRC Warning，类别为 DPIP-1（4 条）、DPOP-1（5 条）、DPOP-2（6 条），属于 DSP 输入/输出流水寄存器建议。另有 41 条 methodology Warning：SYNTH-6（38 条，RAM 时序优化建议）、SYNTH-10（3 条，共享宽乘法器）。不存在由此导致的时序失败。

此前第一次构建的 BRAM 异步控制警告 REQP-1839/1840 已通过顶层同步复位寄存器修改消除，最终位流的 DRC 不再包含这两类警告。完整 HLS 内核未因该顶层复位修正改变；最终三组实物测试均使用修正后的位流。没有降低相关 DRC 严重性或屏蔽内部时序检查。

虽然算法乘法输入先量化为 INT16，HLS 可能为共享/选择逻辑生成较宽的物理乘法器，最终实际 DSP 数量以上表为准。

## 6. 模型来源与验证限制

artifacts/source_provenance.json 记录并核验：

- 用户 software4npu-main.zip 的 SHA256。
- 包内原始模型配置、attention、embedding、encoder_layer 等 7 个文件的 SHA256；vendor 副本逐字节未改。
- 完整预训练 checkpoint 与所含单层权重的 SHA256。
- 固定模型 revision 和选择的 layer/head。

测试参考直接执行原始 RelPositionMultiHeadedAttention，并从 linear_out 的输入抽取目标 head。8 个浮点 head 投影贡献求和加一次 bias 可以重建原始 attention 输出，源参考函数对此有断言。

当前实物覆盖 B=1、T=1/4/8、head=0，以及上述 padding/全屏蔽条件。运行时 T 支持 1..8；同层其他 head 可换原始权重，但未包含在本报告的实物覆盖中。本报告不声称所有可能输入的量化误差都有同样上界，也未评估真实语音识别 WER。
