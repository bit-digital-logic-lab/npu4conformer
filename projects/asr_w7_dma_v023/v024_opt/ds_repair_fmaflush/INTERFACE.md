## 2. Handshake contract (repaired)

1. A transfer exists **iff** `in_valid && in_ready` at a rising edge of `clk`.
2. **`flush` is a full handshake barrier.** While `flush==1`, `in_ready==0`
   combinationally. An upstream that asserts `in_valid` during `flush` has
   **not** transferred anything; it must hold/retry the element after flush.
   There is no drain handshake and no hidden accept.
3. **`out_valid` during the flush cycle is cancelled.** `out_valid==0`
   combinationally while `flush==1`. Therefore the cycle in which `flush` is
   sampled never presents an output transfer, even when `out_ready==1`.
   `flush` aborts every in-flight stage, including a result parked in S7.
   Downstream must treat `flush` as an error abort: no beat is delivered on a
   flush cycle, and any earlier delivered beat is outside this barrier.
4. `flush` is synchronous: at the rising edge where `flush` is sampled high,
   valid bits S1..S7 are cleared. The cycle after `flush` deasserts is a clean
   new epoch; latency from a post-flush accept to its output is 7 cycles.
5. **Reset is also a handshake barrier.** While `rst_n==0`, `in_ready==0` and
   `out_valid==0`, so no transfer is recognized during reset. The flop reset
   style remains asynchronous-assert (same as the trusted core); `rst_n` must
   be deasserted synchronously to `clk`. No port or reset polarity change.
6. Stability: while `out_valid && !out_ready && !flush`, `out_result`,
   `out_tag`, `out_last` are frozen.
7. Throughput is still II=1 when `flush=0`, `rst_n=1`, `out_ready=1`.

## 3. Unchanged numeric contract (explicitly retained, AR-002)

The arithmetic core is copied bit-for-bit and **must not** be changed:

- single-rounding RNE binary32 FMA `result = a*b + c`, 129-bit accumulator;
- FTZ: subnormal inputs are zero, subnormal results flush to signed zero;
- canonical qNaN `0x7fc00000`;
- `inf*0 -> NaN`, `inf + (-inf) -> NaN`;
- exact non-zero cancellation -> `+0`;
- `x*0 + c` (finite non-zero `c`) -> bit-exact `c`;
- **project FTZ signed-zero special retained**: when both addends are FTZ-zero,
  the result sign is `sign(c)` (so `(+0)+(-0) -> -0`), and `inf*subnormal`
  uses raw-bit zero detection for the `inf*0` rule and therefore returns `inf`.
  These are the declared project contract, **not strict IEEE**. They are
  documented here and must not be "fixed" in this task.
