# Assets and missing dependencies

## 1. Included in this export

All included files are small, reproducible fixtures or pure source. See
`FILE_SHA256.txt` for hashes and `ORIGIN_MAP.json` for origin paths.

| Kind | Location | Notes |
|---|---|---|
| RTL | `rtl/**` | 51 selected `.sv` files, one definition per module |
| TB + BFM | `sim/tb/**` | V0.24 unified / epilogue / baseline-smoke TB + safety BFM |
| fixtures/gold | `sim/fixtures/**` | 4 small-graph mem images, A16/I16/lane gold, `v024_ref.json`, 32×32×32 matrix fixture |
| generator | `scripts/sim/gen_v024_graph.py` | deterministic, fixed seed; independent integer + numpy gold |
| independent matrix gold | `scripts/analysis/gen_matrix_gold.py` | copied from `v023_repair/ds_matrix/tests` |
| judge | `scripts/analysis/check_export.py` | checks `REFERENCE_FREEZE.json`, A16/I16/lane, DIV/SQRT tolerance |
| skills | `skills/**` | traffic-ledger + module-activity-waveform |

The fixture images are sparse 2.3 MB text hex files each; `mat32` is
regenerated by the entry script.

## 2. Not included (large / external / missing)

These are intentionally outside the export. They are required only for the
full-model or board claims, which this export does **not** make.

|---|---|---|

| large golden images / 591-tensor fixtures | not present | full graph is not run |

`EXTRACT_MANIFEST.json` at the project root has the original extract hashes.
The small fixtures here are **not** a substitute for the missing full model;
they only exercise the named logic paths.

## 3. Reference metadata freeze

`sim/fixtures/REFERENCE_FREEZE.json` freezes the fixture/gold hashes used by
the judge. Paths were rewritten from `fixtures/...` to `sim/fixtures/...` for
this layout; the bytes are unchanged. The judge refuses to run if a frozen
fixture changes.
