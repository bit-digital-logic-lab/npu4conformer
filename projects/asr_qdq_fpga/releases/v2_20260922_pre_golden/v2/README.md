# 第二代：片上缓冲版（实板算子验收通过）

第一代实板验收冻结目录：`../releases/v1_20260922_board_verified`。
冻结版保留源码、测试、50 MHz 布局布线报告、115200 波特比特流、
实板数值与速度报告、SHA256清单；本目录开发不覆盖第一代。

本版保持原模型12层Encoder、6层Decoder、INT16权重/输入乘法、
48位累加和第一代FP32数值约定。不启用DDR，不写Flash。

目标：128 KiB BRAM保存算子内的向量、分块矩阵及累加结果；批量
执行Q/DQ、归约、Softmax与LayerNorm，减少UART往返。首版INT16每个
32-bit槽保存一个元素，尚未打包。节点间大张量仍允许上位机保存。

`PROTOCOL_V2.md` 是RTL/host共同接口约定。`uart_probe/` 是独立的
921600波特回环资格测试，不是ASR计算或模型推理证据。

只有通过仿真、板级时序/DRC、JTAG版本核对及实板数值比较，才能将
相应功能标为实板通过；未完成整网时不得由算子结果推断整网已通过。

构建与下载（后者只写易失FPGA配置）：

```powershell
./v2/scripts/run_vivado.ps1 -Mode board_build -Baud 921600
./v2/scripts/run_vivado.ps1 -Mode program_board -Baud 921600
```

Vivado只使用已核对的AX7035四个引脚：Y18时钟、F20复位、G15接收、
G16发送；其余用户I/O未启用。计算路径不设置false path/multicycle。

## 2026-09-22 实板结果

JTAG下载成功，DONE=1、CRC_ERROR=0、USR_ACCESS=A5160002。
50MHz布局布线：建立裕量+0.063ns、保持裕量+0.070ns、无未约束内部端点，
bitgen DRC 0 Error（有DSP流水优化建议，非声称所有Warning为零）。
LUT6653/20800（31.99%）、FF2168、DSP6、BRAM36 32/50（64%）。
“64%”只指BRAM，不能说所有资源都占64%。

20项实板测试全部通过；独立RTL503事务、主机单测12项也通过。
31×256×64矩阵tile实测1.569秒；板内2547456周期，50MHz约50.949ms，
其余主要是115903字节通信及主机开销。

| 相同数据夹具 | V1 115200 | V2 921600 | 实测加速 |
| --- | ---: | ---: | ---: |
| INT16 MatMul 8×256×32 | 24.179s | 0.591s | 40.94× |
| Quantize 512元素 | 5.228s | 0.062s | 83.67× |
| LayerNorm 512维 | 18.311s | 0.144s | 127.59× |
| Softmax 4×31 | 3.116s | 0.070s | 44.49× |

这些是算子端到端加速，包含波特率提升，不是整网速度承诺。
921600独立UART全字节+4MiB随机回环无差错，载荷约87.16KB/s。

完整原case0000预计搬运1,853,958,591字节；921600理想线速下限5.588小时。
另取7帧/1token的新短输入，保留全部原模型层和权重，预计499,375,633字节，
线速下限1.505小时。以上不含全部实际延迟，非已完成推理的计时。
